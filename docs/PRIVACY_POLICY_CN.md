## 1. 适用范围

Valnook 是一款免费、开源的个人财务记录与资产管理工具，按 [MIT 许可证](../LICENSE)提供，目前仅通过上述 GitHub 仓库发布。本政策适用于开发者发布的 Valnook 应用及其局域网网页管理功能。第三方修改或重新分发的版本，其数据处理行为由相应提供者负责。

Valnook 以本地存储为主。开发者不运营用于接收或存储应用用户数据的自有服务器，应用不会将您的财务记录、图片或备份上传至开发者自有服务器。使用云端备份、文件导出或网页管理时，相关数据会按您的操作或设置传输至您授权的服务、选择的保存位置或配对的浏览器。

## 2. 处理的信息与用途

| 信息类别 | 内容与用途 |
| --- | --- |
| 财务记录 | 您输入或导入的账户名称、备注、余额、币种、信用额度与账单规则、存款、投资标的、持仓、交易、价格和汇率，用于记录、计算、统计和展示。 |
| 账户图片 | 您通过系统照片选择器选取并裁剪的图片，用作账户图标，并随完整备份保存。 |
| 设置偏好 | 语言、主题、显示与排序等设置，用于保存使用偏好。 |
| 操作历史 | 记录修改前后内容、操作时间等，用于维护记录一致性、历史追溯和备份恢复。部分已删除记录仍可能保留在历史中。 |
| 云端连接信息 | 连接 OneDrive 时处理的微软账户标识、显示名称、邮箱或账户显示信息、授权凭据及备份状态，用于身份验证和管理备份。 |
| 网页会话信息 | 局域网连接地址、浏览器标识、配对及会话凭据、连接和活动时间，用于配对认证、会话管理和访问限制。 |

基础财务管理不要求注册 Valnook 账户或连接云服务。应用不将财务记录用于广告投放、营销画像或出售。

卡包卡面是您通过系统照片选择器主动选择的可选图片。静态 JPEG、PNG 和 WebP 图片的裁剪、旋转、压缩和取色均在本机完成，不保留原图位置等不必要元数据。Valnook 不进行 OCR 识别，也不自动收集卡号、有效期或 CVV，建议使用空白或已遮挡敏感信息的卡面。卡片可关联已有子账户，不会创建新的账户或复制财务记录。卡片图片、绑定关系和顺序均包含在完整本地及云备份中；启用 OneDrive 备份后会随备份上传。网页管理不提供卡面图片资源。删除卡片不会删除关联账户，清空全部数据会同时删除卡包数据。

卡片背面功能仅在真实数据模式提供。您可主动填写卡号、有效期、CVV1 和 CVV2，并设置背面、侧面配色。上述内容使用 Android Keystore 管理密钥，并通过 AES-GCM 加密，独立保存在本设备的应用私有、不备份目录中；不会上传至服务器，不包含在本地完整备份、OneDrive 等云备份、Excel 或其他导出中，网页管理不能访问。它们不进入财务操作历史、日志或页面状态备份。不再显示风险提示的选择也仅保存在本机。 仅在您主动点击复制图标时，对应卡号、有效期或 CVV 才会写入系统剪贴板，并标记为敏感内容以限制系统预览。剪贴板不属于本应用的加密存储，粘贴目标及具备相应权限的软件可能获取该内容，请谨慎复制；应用不会自动复制、记录复制值或因此将其纳入备份和文件导出。

普通重启、应用升级、卡片改名、更换正面图片、换绑或解绑账户不会删除背面内容。删除卡片、清空全部数据或成功覆盖恢复备份会使其本机私密关联失效并清理内容；恢复校验失败或事务回滚时原内容保留。卸载应用、清除应用数据或换机后无法通过备份恢复背面内容。卡片正面图片仍随完整备份保存，包括图片中原有的文字；应用不自动识别或遮挡其中的敏感信息。

卡号、有效期、CVV1 和 CVV2 泄露可能造成财产损失。建议在设备支持时，为 Valnook 启用系统应用锁。背面及编辑窗口显示期间限制系统截图与非安全屏幕显示，进入后台时遮蔽私密内容；本地加密与窗口保护不能保证被攻破设备上的绝对安全。

**Valnook为按照MIT协议发行的开源软件，不对您的财产损失负任何责任**

## 3. 本地存储与权限

财务记录、账户图片、操作历史和相关设置主要保存在设备上的应用私有存储中。应用已配置关闭 Android 系统自动备份，并将相关应用数据排除在系统云备份和设备迁移之外。

应用使用网络访问和网络状态权限支持云端备份及局域网网页管理。图片选择及文件导入、导出通过系统选择器完成，应用读取或写入您选择的内容，不要求获取整个相册或所有存储文件的访问权限。

本地数据依赖操作系统的应用隔离及设备安全机制保护。请妥善保管设备及解锁凭据。

## 4. OneDrive 云端备份

OneDrive 是可选功能。连接时，您通过微软提供的授权流程登录，应用获得读取基本账户资料及管理 OneDrive 应用专用文件夹的权限。登录与授权凭据由微软身份认证组件处理，用于访问您授权的云端空间。

您可以手动创建备份，或另行开启自动备份。自动备份按设定间隔调度，可能在后台运行并使用移动网络，实际执行时间受网络和系统调度影响。关闭自动备份或断开连接不会删除已上传的文件。

完整备份包含财务记录、账户图片、相关设置和操作历史，也可能包含已修改或标记删除的记录。备份相关信息包括生成时间、应用版本、文件大小和完整性校验信息。云端授权凭据不包含在完整备份中。

**备份文件本身未加密。** OneDrive 云端传输使用 HTTPS，但这不等于备份文件采用端到端加密。

应用在成功备份后尝试保留最近 5 份已验证的受管备份，并清理更早的对应备份；清理失败或存在其他文件时，云端可能保留更多内容。云服务回收站及其他保留机制由微软管理。

微软会按照其服务条款和[隐私声明](https://privacy.microsoft.com/privacystatement)处理云服务所需的信息。数据存储和处理地区取决于微软服务及您的账户设置，可能位于您所在地区之外。您可以在微软账户中管理或撤销授权，并在 OneDrive 中管理已有备份。

## 5. 本地备份、导入与导出

您可以将完整备份或 Excel 工作簿保存到系统文件选择器指定的位置，也可以选择备份文件进行恢复。保存位置可能由设备存储或第三方文档、云盘服务提供；选择第三方服务时，文件由该服务按其规则处理。

完整备份与 Excel 导出文件均不提供文件加密。完整备份可包含操作历史，Excel 文件可包含导出范围内的财务及历史信息。请谨慎决定保存位置和分享对象。

恢复备份会覆盖相应的现有数据。清空应用数据或卸载应用不会同步删除您另存的备份、导出文件或其副本。

## 6. 局域网网页管理

您主动开启网页管理并通过二维码或配对码连接后，配对浏览器可以在同一局域网内查看和编辑应用提供的财务数据。数据在手机与浏览器之间传输，不经由开发者自有服务器中转。

**网页管理使用 HTTP 和 WebSocket，不提供传输加密。** 配对认证不等于加密传输。请仅在可信局域网和可信设备上使用，并妥善保管配对信息。

网页使用会话 Cookie 和浏览器会话存储维持认证，使用本地存储保存主题偏好。这些机制用于功能运行，不用于广告跟踪。您可以通过浏览器清除相关网站数据。

网页连续 5 分钟无操作、手机切换到后台或锁屏、或您主动结束会话时，连接会终止。结束会话不会撤回已经在浏览器中复制、截图或另行保存的数据。

## 7. 保留、删除与您的选择

本地业务记录通常保留至您删除记录、清空数据或清除应用存储。操作历史可能比对应的可见记录保留更久。

| 操作 | 效果与边界 |
| --- | --- |
| 查看、编辑或删除记录 | 您可以在应用内管理记录；删除单条记录不保证同时清除操作历史中的相关内容。 |
| 应用内“清空数据” | 清除业务记录、账户图片、既有操作历史及相关财务设置；保留部分偏好和云端连接状态，并记录本次清空事件。此操作不等于断开云服务。 |
| 关闭自动备份或断开 OneDrive | 停止后续自动备份或断开该设备的云端连接；不会删除已经上传的文件，也不等于在微软账户中撤销授权。 |
| 撤销微软授权 | 撤销后续云端访问权限；已有备份仍需在 OneDrive 中管理。 |
| 清除应用存储或卸载 | 移除设备上的相应应用数据；外部文件、云端备份及其他副本不随之删除。 |

导出文件保留至您或相应存储服务删除，云端备份还受前述轮换规则及云服务保留机制影响。开发者不持有您的本地财务数据库或云端备份，无法代您访问、恢复或删除这些内容。有关隐私的问题可以通过本政策中的邮箱联系。
