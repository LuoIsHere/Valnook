# Google Drive Backup

Google Drive backup is disabled because of Google's API policy requirements. Valnook currently backs up to OneDrive; see [How OneDrive Backup Works](ONEDRIVE_BACKUP.md).

Backups saved to Google Drive by earlier builds are ordinary `.val_backup` files. To use one, download it to the device and choose it in the app's local restore. It goes through the same validation, preview, and overwrite confirmation as any other backup.
